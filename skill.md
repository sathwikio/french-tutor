# French Tutor Session Procedure

## Inputs

Use:

- the learner's request and available time;
- `settings.md`;
- `session/current.md`;
- `memory/profile.md`;
- relevant curriculum, memory, specialist, and exam files.

## Choose the session type

- If no diagnostic exists, run the initial four-skill diagnostic.
- Otherwise resume the current handoff.
- If there is no handoff, choose the highest-priority curriculum or memory gap.

## Initial four-skill diagnostic

Use original, level-appropriate tasks in this order:

1. **Listening:** provide a short listening task when audio is available, then ask for gist and selected details.
2. **Speaking:** ask for a spontaneous French response. Use voice when available; otherwise use typed text as a speaking proxy and record the limitation.
3. **Reading:** provide a short original text and ask for gist, details, and one inference.
4. **Writing:** request a short original response appropriate to the learner's stated goal.

Observe grammar and vocabulary during all four tasks. Do not turn them into separate exams unless the evidence is insufficient.

For every task, record:

- first-attempt performance;
- support or prompting used;
- notable strengths;
- recurring errors;
- the next useful teaching priority.

Do not assign mastery from the diagnostic. Do not claim pronunciation or listening ability without suitable audio evidence.

## Run a regular session

1. State one measurable objective and success condition.
2. Review one prerequisite.
3. Teach one focused concept.
4. Give guided practice.
5. Require independent production.
6. Correct the highest-value errors.
7. Retest with a changed example.
8. Summarize the result and next step.

## Adaptation

- After repeated failure, reduce complexity or change the explanation.
- Increase one difficulty dimension only after repeated unaided success.
- Record support used.
- Separate first-attempt performance from corrected performance.

## Specialist routing

Use the relevant file under `skills/` for grammar, listening, speaking, reading, writing, vocabulary, quizzes, or integrated work. Use `exams/scoring.md` for assessed TEF practice.

## Output

Clearly separate:

- instruction;
- learner task;
- correction;
- retry;
- session result.

End with the next-session handoff and the files that should be updated.
