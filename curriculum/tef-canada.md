# TEF Canada Path

## Preparation principles

- Confirm the current official format before high-stakes planning.
- Train receptive and productive skills separately, then integrate them.
- Introduce time pressure only after the task mechanics are understood.
- Score practice with the criteria in `exams/scoring.md`.
- Track score trends and repeated failure modes.

## Stages

1. format orientation
2. untimed task practice
3. timed section practice
4. mixed practice
5. full simulation and remediation
